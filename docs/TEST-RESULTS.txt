UPLOAD PERFORMANCE CONTRACT AFTER BUILD
- selected image is decoded/oriented in the browser
- source is never upscaled; configured max dimensions default to 2560 × 2560
- encoding runs in a Web Worker where supported by the required browser path
- highest WebP quality under 480 KB is selected by bounded binary search
- if minimum quality misses 480 KB, dimensions fall by 10% and the search repeats
- browser refuses a final result above 500 KB
- PHP validates final MIME + size only; it does not recompress the MediaFlow browser source
- normal WordPress attachment handling continues after validation
- existing MediaFlow derivative/static-cache delivery plane remains separate
