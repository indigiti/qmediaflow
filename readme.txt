Experimental on-demand responsive image engine with a disposable static cache.

== Description ==

MediaFlow keeps WordPress source attachments under normal media management and generates optimized image variants only when requested.

v0.2 hardens the architecture for large media libraries with sharded filesystem storage, non-blocking anti-stampede generation, O(1) logical cache rotation, private filesystem manifests/settings, bounded responsive candidates and lightweight progressive placeholders.

Cached generated images are real static files. Normal cache-hit delivery does not bootstrap WordPress or execute MediaFlow PHP.

== Important ==

This is a staging/development build. Test theme and plugin compatibility before reducing normal WordPress physical image sizes on an established site.

If the default private directory is web-accessible on Nginx, deny `/.mediaflow-private/` or define `MEDIAFLOW_PRIVATE_DIR` to a path outside the document root.

== Changelog ==

= 0.2.8 =
* Add browser-first image upload optimization with orientation normalization, dimension limits and Web Worker WebP encoding.
* Binary-search the highest quality under a 480 KB target; reduce dimensions by 10% and retry when needed.
* Enforce a final WebP ceiling of 500 KB without server-side recompression.
* Add configurable 2560×2560 upload dimensions and 25 MB original browser-processing limit.
* Avoid double processing with WordPress 7.1+ client-side media while MediaFlow owns the upload transform.

= 0.2.7 =
* Add Auto LQIP: deterministic gradient first, then a revisioned static LQIP generated by a bounded background queue.
* Keep missing Auto-LQIPs out of WordPress/PHP on Apache/LiteSpeed by serving a transparent no-store static pending fallback.
* Add queue deduplication, retry state, one-image WP-Cron worker runs and a bounded generation lock pool.
* Make full Media Library LQIP rebuild optional; retain pre-warm controls and WP-CLI for administrators who want previews ready in advance.
* Preserve Inline LQIP, single-decode generation, src/srcset behavior, multisite protections and static derivative delivery.

= 0.2.6.1 =
* Decode each source only once during adaptive LQIP fallback generation.
* Add a request-global total inline LQIP byte budget (24 KB default) that survives multisite context reloads.
* Memoize successful path/guard setup within the request and separate routing schema migrations from plugin version updates.
* Time-bound wp-admin rebuild requests, lower default AJAX batch size to 5, and lower WP-CLI default to 100.
* Add performance-hardening regression coverage without changing real src/srcset discovery behavior.

= 0.2.6 =
* Configurable 16/32/64/128/256px inline LQIP previews with 64px default.
* Adaptive inline-byte budgeting and per-page LQIP cap with color fallback.
* Bounded wp-admin and WP-CLI rebuilds for existing Media Library images.
* Preserves real src/srcset loading behavior and the 0.2.5 multisite recursion hotfix.

= 0.2.5 =
* Bound multisite context re-entry and preserve the last complete service graph on failed reloads.
* Keep site-switching out of Apache-rule construction and preserve routing guard repairs.

= 0.2.3 =
* Fix Apache HTTP 500 caused by the v0.2.2 `Options -Indexes` public cache guard on restricted AllowOverride configurations.
* Add explicit cache-root cold-miss rewriting to WordPress while preserving direct static cache hits.
* Auto-migrate existing single-site and multisite MediaFlow guard files without replacing unrelated custom directives.
* Remove the legacy Options directive from private MediaFlow guards while retaining deny rules.

= 0.2.2 =
* Scale-hardening build: sharding, anti-stampede, private runtime storage, cache namespaces, bounded srcset, compatibility modes and WP-CLI maintenance.

= 0.1.0 =
* Initial prototype.
